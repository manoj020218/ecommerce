# UI Refactor Request: Align Live E-commerce Site with UX Prototype Layout

## Objective
Refactor the live product detail page layout (`test.jenixindia.com`) to match the structural architecture, B2B features, and design hierarchy of our local UX prototype (`product-detail.html`). Move away from standard B2C template limits to a high-converting, trust-focused B2B/B2C hybrid layout.

---

## 1. Global Component Layout & Styling
- **Framework:** Refactor using a symmetric 2-column grid layout on desktop scales (`md:grid-cols-2 gap-8 max-w-7xl mx-auto px-4 py-8`).
- **Typography:** Enforce a clean, technical sans-serif font stack (e.g., `Plus Jakarta Sans` or `Inter`).
- **Color Palette:** Maintain a high-contrast theme: Deep Charcoal/Near-Black (`#111827`) for background depth headers, clean Solid White (`#FFFFFF`) for semantic content blocks, and Bright Red (`#DC2626`) exclusively for critical actionable highlights.

---

## 2. Left Column: Product Gallery Overhaul
- **Main Image Container:** 
  - Restructure into a perfect square aspect ratio element (`aspect-square w-full`).
  - Style with a subtle light gray border (`border border-gray-100`), soft corner rounding (`rounded-xl`), and center the image inside.
- **Absolute Badges Overlays:**
  - **Top-Left:** Implement a red discount percentage sticker: `bg-red-600 text-white font-bold px-3 py-1 text-sm rounded-md` (e.g., "-15% OFF").
  - **Top-Right:** Implement a clean, desaturated SKU label: `bg-gray-100 text-gray-600 px-3 py-1 text-sm rounded-md`.
- **Thumbnails Row (`mt-4 flex gap-3`):**
  - Implement a row of uniform square mini-cards (`w-16 h-16 aspect-square border rounded-lg p-1`).
  - Active image state must feature a high-contrast red border ring: `border-2 border-red-600`.
