# Phase 13 Regression Checklist

- [ ] Published blog is visible on `GET /api/blogs`.
- [ ] Draft blog is hidden from `GET /api/blogs` and `GET /api/blogs/:slug`.
- [ ] Blog detail shows linked products.
- [ ] Product page payload includes helpful guides from linked blogs.
- [ ] `GET /sitemap.xml` contains published guide URLs.
- [ ] Blog detail returns valid `Article` JSON-LD.
- [ ] Blog detail returns FAQ schema when FAQ items exist.
