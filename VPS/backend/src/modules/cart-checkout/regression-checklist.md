# Phase 7 Cart / Checkout Regression Checklist

- [ ] Guest cart supports add/update/view/remove.
- [ ] Customer cart supports add/update/view/remove.
- [ ] Guest cart can merge into logged-in customer cart.
- [ ] MOQ validation blocks qty below minimum.
- [ ] Bulk slab pricing applies based on qty.
- [ ] Quote-required qty blocks direct checkout and creates quote request.
- [ ] Stock reservation is created on online checkout start.
- [ ] Payment failure releases reserved stock.
- [ ] Simultaneous checkout cannot oversell.
- [ ] Shared cart link can be claimed on another session/device for checkout continuity.
