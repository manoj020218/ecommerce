# Phase 3 HSN/Tax Regression Checklist

- [ ] Admin can create HSN records with GST/CGST/SGST/IGST.
- [ ] HSN record validates `CGST + SGST == GST`.
- [ ] HSN record validates `IGST == GST`.
- [ ] Admin can update HSN metadata and rates.
- [ ] Archiving HSN is blocked when active products use that HSN.
